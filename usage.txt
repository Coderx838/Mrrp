~~~ Mrrp usage notes ~~~
hey! this is just me explaining how mrrp works.
yay cat have language now *mrrp*

to run anything:
  python mrrp.py yourfile.mrrp
files always end with .mrrp
or just type: python mrrp.py  and you get the little repl.

--- the words ---

mrrp
  you put this on top of the file. its like saying "hey cat".
  if you forget it, cat doesnt care. it still runs.

meow <something>
  this is print. thats it.
  meow "hello"
  meow 2 + 3
  meow myToy

paw <name> = <value>
  this is how you make a toy (variable).
  paw snacks = 5
  you can also write: paw snacks is 5
  if you forget the =, cat adds it for you.

sniff <name>
  this asks the hooman to type something.
  sniff snack

purr <condition> {
  this is IF. cat purrs when happy (true).
  purr snacks > 3 {
    meow "yum"
    }

hiss {}
  this is ELSE. cat hisses when grumpy.
  put it after a purr block.

hiss purr <condition> {
  this is ELSE-IF. yes, double cat sound.
  purr n > 10 {
    meow "big"
    }
  hiss purr n > 5 {
    meow "medium"
    }
  hiss {
    meow "small"
  }

chase <condition> {
  this is WHILE. cat chases its tail until tired.
  paw n = 0
  chase n < 3 {
    meow n
    n = n + 1
  }

zoomies <var> from <a> to <b> {
  this is FOR. both ends included, thats friendlier.
  zoomies i from 1 to 5 {
    meow i
  }
  you can add step: zoomies i from 1 to 10 step 2 {

trick <name>(a, b) {
  this is FUNCTION. a trick the cat learned.
  trick add(a, b) {
    fetch a + b
  }
  meow add(2, 3)

fetch <value>
  this is RETURN. cat fetches the toy back.
  only works inside a trick.

--- time travel stuff (the cool part) ---

bury <toy>
  cat buries the toy in the time-hole to save it.
  paw treasure = 999
  bury treasure

dig <toy>
  cat digs it back up. the crazy bit:
  you can dig BEFORE you bury, and it still works.
  meow dig treasure
  paw treasure = 999
  bury treasure
  -> prints 999 on the first line too. from the future!

  you can also use it inside math:
  meow dig treasure + 1

prophecy <toy> will be <value>
  you tell the cat what the future will be.
  prophecy dinner will be "tuna"
  now "dinner" is tuna, now AND in the future.

prophecy <toy>
  just peeks at the future.
  meow prophecy dinner

flashback <toy>
  goes back to what the toy was before.
  paw mood = "sleepy"
  paw mood = "zoomies"
  flashback mood
  meow mood   -> sleepy again

lives
  cat tells you how many of its 9 lives are left,
  plus what is buried and what it saw in the future.

rewind
  resets EVERYTHING to the very first values.
  like waking up from a nap.

nap
  does nothing. cat naps. useful as a placeholder.


----- adopt + borrow ( new feature in v0.2.0 !!)
borrow <python_module>
  this lets mrrp call real python. like native extensions. yay !!
  borrow random
  paw luck = random.randint(1, 6)
  meow luck
  borrow math
  meow math.sqrt(16)
  meow math.pi
  you can borrow more than one:
    borrow math, random
    borrow random as rnd
    paw luck = rnd.randint(1, 6)
  after borrow, both work:
    random.randint(1, 6)   (qualified, recommended)
    randint(1, 6)          (unqualified, if no name clash)
  string toys work too:
    paw s = "hey"
    meow s.upper()
  if the module is missing, cat loses 1 life and keeps going.
  never crashes.

adopt <name>
  this is like import in python. it grabs tricks from another .mrrp file.
  # in math_cat.mrrp:
  # trick add(a, b) {
  #   fetch a + b
  # }
  # in main.mrrp:
  adopt math_cat
  meow add(10, 20)   -> 30
  rules:
  - looks for <name>.mrrp next to your script first, then in cat_pack/ or lib/
  - runs that file with the SAME cat, so its tricks + paws land in your scope
  - adopting the same file twice is skipped (no infinite zoomies)
  - missing file = lose 1 life, keep going. never crashes.

cat_pack/ (the standard library folder)
  this folder sits next to mrrp.py (and next to mrrp.exe in releases).
  mrrp looks there automatically when you adopt.
  right now it has:
  - math.mrrp:    add, sub, pow, abs, sqrt, min, max
    adopt math
    meow add(10, 20)
    meow pow(2, 8)
  - strings.mrrp: repeat_cat, shout, whisper, reverse_cat, hug
    adopt strings
    meow shout("hey cat")
    meow reverse_cat("mrrp")
  - games.mrrp:   dice, dice20, coin (uses borrow random inside!)
    adopt games
    meow dice()
    meow coin()
  try it all at once:
    python mrrp.py examples/power_pack.mrrp  

--- tiny things ---

yum / yuck
  true and false. cat words.
  true / false also work if you forget.
  paw happy = yum

math: + - * / %
compare: == != < > <= >=
  (if you type = in a purr, cat knows you meant ==)
logic: and or not

comments:
  # i am a note
  // me too

---- the never crashing stuff(why is never yells at you) ----

- typos get fixed: meooow becomes meow
- wrong toy names get guessed: tream -> treasure
- missing " or ) or } get closed by the tail
- unknown toy becomes 0
- 10 / 0 does NOT crash. cat loses 1 life and keeps going.
- any confusing line becomes a nap, never an error.
